# Plain-language decisions — parts disco

The reader this file is kept for: someone who plays free browser games, followed a
link, and does not write code. Everything below the "Running it yourself" heading in
`README.md` is read by developers instead, so a word that is fine there can still be
a wall higher up.

## Decided - replace

- board: yard
- shell: car
- filesystem: say what the reader would do — "do not double-click index.html"

## Decided - keep and gloss

- CC0: released into the public domain

## Decided - fine as-is

- yard
- ES
- fetch
- MIT
- LICENSE
- README
- URL
- VT323
- SIL
- ROM
- kenney's
- suvs
